# MovieKG — Ontoloji Tabanlı Film Bilgi Grafiği

Film alanı için **OWL ontolojisiyle** tasarlanmış bir RDF bilgi grafiğinin tanıtım sitesi.

🔗 **Canlı site:** https://ontology-development-project.vercel.app

## İçerik

- OWL ontolojisi ve TMDb verisinden üretilen RDF bilgi grafiği
- SPARQL sorguları ve SHACL doğrulama
- OWL-RL çıkarımı (reasoning)
- LLM destekli doğal dilden SPARQL'e (NL2SPARQL) soru-cevap

**Ekip:** Adile Nisa Güngör · Ferhat Baydır · Furkan Çetin
